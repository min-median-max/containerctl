# 체크리스트

[English](checklist.md)

- [o] CT-1 실행 중인 소유 서비스를 교체 전에 중지한다. 우선순위: 서비스 교체의 정확성. 완료 기준: 추적하는 RED가 강제 옵션 없는 제거 전 중지, 이미 중지된 서비스 제거, 중지 실패 후 제거 미실행을 검증한다. 소유 도구 검사와 소비 엣지를 재시작하지 않는 실제 HTTPS 교체 검증을 실행한다. 기존 볼륨과 무관한 프로젝트를 보존한다.

CT-1은 수명주기 성공 전에 Apple 네이티브 서비스 이름이 실행 중인 컨테이너 주소와 같아야 한다. DNS는 변경 이벤트를 노출하지 않으므로 제한된 준비 상태 조회를 허용하며 불일치와 시간 초과를 보고해야 한다. 문서 요청은 재시도하지 않는다.

완료 근거: 강제 제거와 의존 서비스 시작의 추적 RED 사례, 교체·호스트 이름 GREEN 사례, `make check`, 엣지나 DNS 재시작 없는 두 서비스 교체 후 실제 HTTPS 요청. CLI는 빌드했으며 미설치다.
