# 읽기 전용 진단

[English](diagnostics.md) · [명령 계약](cli.md).

`status`와 JSON 출력, `doctor`, 창의 머신 스냅샷은 상태만 읽는다. Compose
프로젝트를 등록·갱신하거나 디렉터리·인증서를 생성하지 않고, CA 개인 키를 읽거나
신뢰·resolver 설정을 변경하거나 DNS 에이전트를 설치하지 않는다. 없거나 읽을 수
없는 공개 인증서는 결과에 표시한다.
공개 CA를 읽지 못하면 JSON에 `certificates.authority.readError`가 포함된다.
공개 인증서를 읽을 수 있다는 사실이 서명 키를 사용할 수 있음을 증명하지는 않는다.

`status`는 등록된 프로젝트를 나열한다. 미등록 Compose 파일을 선택해도 머신 상태에
추가하지 않는다. `doctor`는 이후 `up`에 필요한 준비를 설명할 때 선택 파일의
도메인을 포함할 수 있지만 선택을 저장하지 않는다.

`up`, `install`, 창의 명시적 등록은 기존 등록·설정 효과를 유지한다. 읽기 전용
진단은 해당 작업을 수행하지 않는다. 준비된 머신이 필요한 호출자는 자체 서비스를
변경하기 전에 표시된 CA 신뢰·남은 설정 단계·DNS 상태·proxy 상태를 확인한다.

테스트는 격리 머신 디렉터리와 container·신뢰·launchd 조회용 fixture 실행 파일을
사용한다. 없는 상태가 생성되지 않음, 기존 파일과 수정 시각 유지, Compose 선택 시
등록 불변, 개인 키 없이 공개 인증서 정보 조회를 검증한다.
